所闻，即所见。Hear it. Read it.

AudioScript 声稿是一款离线优先的桌面应用：监听电脑正在播放的声音，把外语播客、视频和会议实时变成原文与译文的双语字幕。识别和翻译都在这台机器上完成，内置中英文模型，可选 29+ 种语言。 AudioScript is an offline-first desktop app that listens to whatever your computer is playing and turns foreign podcasts, videos, and meetings into live bilingual subtitles: source text on top, translation below. Recognition and translation both run on your machine. Chinese and English models are built in, with 29+ languages available.

01 · 起点The starting point

让语言不再是一道坎。Make language one less barrier.

之前转字幕、传录音、配声卡，每一步都在消磨热情和劝退小白。Transcribing subtitles, uploading recordings, wiring up sound cards: every step drained enthusiasm and turned beginners away.

时效Timeliness

告别字幕组No subtitle crew

播客、直播和会议没有现成字幕，等别人做完，内容已经凉了。Podcasts, live streams, and meetings ship without subtitles. By the time someone writes them, the moment has passed.

字幕跟着声音出现，句末就定稿。Subtitles follow the audio and settle at the end of each sentence.

07 · 常见问题FAQ

常见问题解答Frequently asked questions

免费吗？Is it free?

免费，MIT 开源。多语言模型可选下载，其中 NLLB-200 仅限非商业用途。Free and MIT-licensed. Multilingual models are optional downloads; NLLB-200 is for non-commercial use only.

支持哪些系统和语言？音频会上传吗？Which systems and languages are supported? Is my audio uploaded?

macOS 14.2 及以上的 Apple Silicon、Windows 10 及以上、Ubuntu 24，不提供 Intel Mac 版本。中英互译开箱即用，翻译方向需手动选择；多语言模型可选下载，macOS 26 及以上可用系统识别与翻译。
识别与翻译都在本机完成，只有模型下载与更新检查需要联网；
Aptabase 匿名统计不含音频与文本，可在「通用 → 隐私」关闭。macOS 14.2+ on Apple Silicon, Windows 10+, Ubuntu 24; no Intel Mac build. English ↔ Chinese works out of the box and you pick the translation direction; optional multilingual models are available, and macOS 26+ offers system recognition and translation.
Recognition and translation run locally; only model downloads and update checks need the network.
The anonymous Aptabase stats exclude audio and text and can be disabled under General → Privacy.

macOS 提示应用已损坏，无法打开？macOS says the app is damaged and will not open?

这是 Gatekeeper 拦截未签名构建的提示，不是文件损坏。把应用拖入「应用程序」后，在终端执行下面的命令：xattr -dr com.apple.quarantine /Applications/AudioScript.app 即可正常打开。Gatekeeper is blocking an unsigned build; the file itself is fine. Drag the app to Applications, then run this command in Terminal:xattr -dr com.apple.quarantine /Applications/AudioScript.app The app will open normally.

悬浮窗能盖住全屏吗？Linux 不置顶怎么办？Does the overlay cover full screen? What about Linux?

macOS 上悬浮窗以 NSPanel 显示，可盖住其他应用的全屏窗口；Windows 除独占全屏游戏外都行。Wayland 不支持普通窗口置顶，X11 桌面默认正常。GNOME 等桌面启动时请设置环境变量：GDK_BACKEND=x11On macOS the overlay runs as an NSPanel and covers other apps in full screen; on Windows it works except in exclusive full-screen games. Wayland has no keep-above for regular windows; X11 desktops work out of the box. On GNOME and similar desktops, set this environment variable when launching:GDK_BACKEND=x11

Windows 提示「已保护你的电脑」「未知发布者」，或被智能应用控制拦截？Windows shows “Windows protected your PC”, “Unknown publisher”, or Smart App Control blocked it?

这是 Windows 对未签名安装包的拦截，安装包本身没有损坏。
SmartScreen 提示：「更多信息 → 仍要运行」，或先右键安装包 →「属性」→ 勾选「解除锁定」再安装。
智能应用控制：需在 Windows 安全中心 →「应用和浏览器控制」→「智能应用控制」中关闭后再安装。Windows is blocking an unsigned installer; the file itself is fine.
SmartScreen: choose “More info → Run anyway”, or right-click the installer → Properties → check “Unblock” before installing.
Smart App Control: turn it off under Windows Security → App & browser control → Smart App Control, then install.
