05 / FAQ

还有一些问题。A few questions.

音频会上传吗？Is my audio uploaded?

不会。识别与翻译都在本机完成，音频与文本不上传。可选模型下载与检查更新需要联网。No. Recognition and translation run locally; audio and text are not uploaded. Optional model downloads and update checks need network.

支持哪些语言？Which languages are supported?

英语 ↔ 中文，需要手动选择翻译方向；不支持自动语言检测。English ↔ Chinese. You choose the direction; there is no automatic language detection.

需要安装 BlackHole 之类的虚拟声卡吗？Do I need BlackHole or another virtual audio driver?

不需要。macOS 使用 Core Audio Process Tap，Windows 使用 WASAPI loopback。首次采集系统声音时需授予屏幕与系统音频录制权限。No. macOS uses Core Audio Process Tap and Windows uses WASAPI loopback. The first system-audio capture requires Screen & System Audio Recording permission.

为什么开始后要等一两秒才出字？Why does the first line take a second or two?

首次开始需要加载识别与翻译模型，实测约 1.25–2.2 秒；之后进入流式输出。The first run loads the ASR and translation models, measured at about 1.25–2.2 seconds. After that it streams.
